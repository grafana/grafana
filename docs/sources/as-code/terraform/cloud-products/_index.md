# Manage Grafana Cloud products with Terraform

Use these guides to configure Grafana Cloud products with Terraform. To follow them, you need a Grafana Cloud stack. To create one with Terraform, refer to [Create and manage a Grafana Cloud stack using Terraform](../terraform-cloud-stack/).

{{< section withDescriptions="true" >}}

## Guides in other sections

The following Grafana Cloud products document Terraform in their own sections:

- **Fleet Management:** [Terraform and Fleet Management](https://grafana.com/docs/grafana-cloud/send-data/fleet-management/set-up/infrastructure-as-code/terraform/) — Review additional Terraform documentation for Fleet Management in the Grafana Cloud docs.
- **Grafana Assistant:** [Manage Grafana Assistant with Terraform](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/configure/terraform/) — Manage Assistant rules, skills, quickstarts, MCP servers, and terms acceptance.
- **Grafana Cloud integrations:** [Install and manage integrations using Terraform](https://grafana.com/docs/grafana-cloud/monitor-infrastructure/integrations/manage-integrations-using-terraform/) — Install, update, and remove the dashboards and alerts of Grafana Cloud integrations.
- **IRM:** [Infrastructure as code](https://grafana.com/docs/grafana-cloud/alerting-and-irm/irm/set-up/infra-as-code/) and [Schedules as code](https://grafana.com/docs/grafana-cloud/alerting-and-irm/irm/on-call-schedules/schedules-as-code/) — Review additional Terraform guides for Grafana IRM in the Grafana Cloud docs.
- **Machine Learning:** [Provision Machine Learning resources using Terraform](https://grafana.com/docs/grafana-cloud/ai-tools/machine-learning/additional-configuration/terraform/) — Create forecasts, holidays, and outlier detectors, and their alert rules.
- **SLO:** [Provision SLO resources using Terraform](https://grafana.com/docs/grafana-cloud/alerting-and-irm/slo/set-up/terraform/) — Define SLOs, export existing SLOs as Terraform, and import them into Terraform state.
- **Workflows:** [Use Terraform](https://grafana.com/docs/grafana-cloud/platform/workflows/as-code/use-terraform/) — Create, update, and delete workflows from YAML definitions. Grafana Workflows is in public preview.

For the full list across Grafana and Grafana Cloud, refer to the [Terraform guides by area](../#terraform-guides-by-area).

# Get started with Terraform

Use these guides to configure the Grafana Terraform provider and create your first resources. Choose the guide that matches your deployment:

- **Self-managed Grafana:** Authenticate with a service account token and add a data source, a folder, and a dashboard to an existing Grafana OSS or Grafana Enterprise instance.
- **Grafana Cloud:** Create a Grafana Cloud stack and its service account, and then add a data source, a folder, and a dashboard to the stack.

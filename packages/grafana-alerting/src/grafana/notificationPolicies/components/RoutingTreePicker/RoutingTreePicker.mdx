# RoutingTreePicker

A component for picking which notification policy tree routes an alert rule, with no dependency
on the alert-rule form. Built on top of `RoutingTreeSelector`, adding the collapsed
"Default policy" badge / "Change" / "Reset to default" interaction. Only works with the built-in
Grafana Alertmanager.

⚠️ This component's shape is still exploratory and may change before it stabilizes.

It fetches through the `notifications.alerting/v1beta1` RTK Query client (the same one
`RoutingTreeSelector` uses), so the host app's Redux store needs that API's reducer and middleware
registered, and a `<Provider>` wrapping the tree - see `configureStore.ts` for how Grafana core
wires this in. No `RuleFormValues` or `AlertmanagerProvider` is required.

## Basic usage

`value` is `null` when the default policy applies - nothing has been explicitly chosen yet.

```tsx
import { RoutingTreePicker } from '@grafana/alerting/unstable';
import type { RoutingTree } from '@grafana/api-clients/rtkq/notifications.alerting/v1beta1';

function MyComponent() {
  const [value, setValue] = useState<RoutingTree | null>(null);

  return <RoutingTreePicker value={value} onChange={setValue} viewPoliciesHref="/alerting/routes" />;
}
```

## With a "who would get notified" preview

Pass `instancesToPreview` to show which policy route would receive a notification for a given set
of alert instance labels. This works whether `value` is an explicit tree or `null` (the default
policy) - the preview resolves the actual default tree itself when nothing is explicitly selected.

```tsx
import { RoutingTreePicker } from '@grafana/alerting/unstable';
import type { RoutingTree } from '@grafana/api-clients/rtkq/notifications.alerting/v1beta1';
import type { Label } from '@grafana/alerting';

function MyComponent() {
  const [value, setValue] = useState<RoutingTree | null>(null);

  const labels: Label[] = [
    ['severity', 'critical'],
    ['team', 'platform'],
  ];

  return <RoutingTreePicker value={value} onChange={setValue} instancesToPreview={[labels]} />;
}
```

## Testing

Tests that render this component need jsdom's combobox-rect shim, since `RoutingTreeSelector`'s
`Combobox` reads layout measurements jsdom doesn't provide by default:

```tsx
import { mockComboboxRect } from '@grafana/test-utils';

beforeAll(() => {
  mockComboboxRect();
});
```

Without it, the dropdown can't be opened or driven in tests.

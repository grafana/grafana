# Collapse

A content area, which can be horizontally collapsed and expanded. Can be used to hide extra information on the page.

## Usage

```jsx
const [isOpen, setIsOpen] = useState(false);

<Collapse label="Collapse panel" isOpen={isOpen} onToggle={() => setIsOpen(!isOpen)}>
  <p>Panel data</p>
</Collapse>;
```

### Data attributes

`Collapse` and `ControlledCollapse` render any `data-*` attribute, for example `data-analytics-id`, on the toggle button.

```jsx
<ControlledCollapse label="Query options" data-analytics-id="query_options_toggle">
  <p>Panel data</p>
</ControlledCollapse>
```

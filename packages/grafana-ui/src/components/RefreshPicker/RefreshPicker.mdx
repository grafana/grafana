# Refresh Picker

## When to use

Use `RefreshPicker` to offer manual refresh and an optional automatic refresh interval.

## Never use for

No component-specific guidance documented yet.

## Do's and don'ts

Place `RefreshPicker` next to [TimeRangePicker](?path=/docs/date-time-pickers-timerangepicker--docs) in the toolbar. Omit `text` and `loadingText` for an icon-only refresh button when space is tight.

## Usage

The refresh button calls `onRefresh`. Set `text` to give the button a visible label.

The interval dropdown calls `onIntervalChanged` when users choose an interval. Set `noIntervalPicker` to show only the manual refresh button. The caller handles the refresh and scheduling.

`isOnCanvas` defaults to `true`. Set it to `false` to use the default toolbar style outside the canvas. `primary` and `isLive` take precedence over this setting.

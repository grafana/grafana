# CodeMirrorEditor

A code editor component using CodeMirror.

### Usage

```tsx
import { CodeMirrorEditor } from '@grafana/ui/unstable';

<CodeMirrorEditor value="SELECT 1" onChange={() => {}} />;
```

### Overview ruler

Set `overviewRuler` to show errors from installed lint extensions in a strip beside the
scrollbar. Clicking a marker selects and scrolls to the error. The strip is off by default;
it does not enable validation. Supply a linter through `extensions`, as shown in the
`WithOverviewRuler` story.

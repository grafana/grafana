# FilterInput

A text input used to filter a list that's already loaded, rather than to search a wider dataset.

## Usage

Use the `variant` prop to make that distinction visible: keep the default `search` variant when the field queries a wider dataset, or switch to `filter` when it only narrows down what's already on screen.

```jsx
import { FilterInput } from '@grafana/ui';

<FilterInput value={value} onChange={setValue} placeholder="Filter..." variant="filter" />;
```

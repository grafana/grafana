# ErrorBoundary

A React component that catches errors in child components.

## When to use

Useful for logging or displaying a fallback UI in case of errors.

## Never use for

No component-specific guidance documented yet.

## Do's and don'ts

No component-specific guidance documented yet.

## Usage

### ErrorBoundary

```jsx
import { ErrorBoundary, Alert } from '@grafana/ui';

<ErrorBoundary>
  {({ error }) => {
    if (error) {
      return <Alert title={error.message} />;
    }
    return <Component />;
  }}
</ErrorBoundary>;
```

### ErrorBoundaryAlert

An error boundary component with built-in alert to display in case of error.

```jsx
import { ErrorBoundaryAlert } from '@grafana/ui';

<ErrorBoundaryAlert>
  <Component />
</ErrorBoundaryAlert>;
```

### ErrorWithStack

A component that displays error together with its stack trace.

```jsx
import { ErrorWithStack } from '@grafana/ui';

<ErrorWithStack error={new Error('Test error')} title={'Unexpected error'} errorInfo={null} />;
```

### withErrorBoundary

a HOC to conveniently wrap component in an error boundary

```jsx
import { withErrorBoundary } from '@grafana/ui';

interface MyCompProps {}

const MyComp = withErrorBoundary(
  (props: MyCompProps) => {
    return <>...</>;
  },
  { style: 'page' }
);
```

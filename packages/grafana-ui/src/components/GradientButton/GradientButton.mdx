# GradientButton

`GradientButton` is a button with a violet to orange gradient from the `theme.colors.gradients.ai` theme token. It has the same sizes, icon, tooltip, focus ring and disabled look as `Button`.

## When to use

Use `GradientButton` for the entry point to Grafana Assistant or another AI feature, such as "Analyze with Assistant".

<Canvas of={GradientButtonStories.Examples} />

## Never use for

- **Ordinary actions.** Use [`Button`](https://github.com/grafana/grafana/blob/main/packages/grafana-ui/src/components/Button/Button.mdx). The gradient loses its meaning when it shows up on unrelated actions.
- **A decorative highlight.** Don't use the gradient to draw attention to something that isn't an AI action.
- **Navigation.** `GradientButton` always renders a `<button>`. Use [`LinkButton`](https://github.com/grafana/grafana/blob/main/packages/grafana-ui/src/components/Button/Button.mdx#links) for a link that looks like a button.

## Do's and don'ts

### Use the ai-sparkle icon

`GradientButton` shows the `ai-sparkle` icon by default, so the button reads as an AI action even without the gradient.

### Use isLoading only for the loading indicator

`isLoading` shows a spinner in place of the icon and ignores clicks until it's `false` again. Use it when there's nothing to do but wait.

If the user can interrupt the action, such as a start/stop or cancel button, control it yourself: keep the state in the caller and swap `icon` and `onClick` to match, for example `square-shape` with a stop handler while a response is generating.

### Keep the Assistant logic in @grafana/assistant

`GradientButton` is only the visual treatment. Opening Assistant, checking whether it is available and tracking usage stay in `@grafana/assistant`, for example in `OpenAssistantButton`. Don't rebuild that logic around a plain `GradientButton`.

### Don't restyle the gradient

`GradientButton` doesn't accept `className`, so its border, background and text color stay consistent. To change the gradient, change the `theme.colors.gradients.ai` token in the theme.

### Space it from the parent

Spacing around a component is the parent's job, so wrap the button in a layout component such as [`Box`](https://github.com/grafana/grafana/blob/main/packages/grafana-ui/src/components/Layout/Box/Box.mdx) or `Stack`:

```tsx
<Box paddingLeft={1}>
  <GradientButton onClick={openAssistant}>Explain panel</GradientButton>
</Box>
```

## Usage

```tsx
import { GradientButton } from '@grafana/ui';

<GradientButton onClick={openAssistant}>Analyze with Assistant</GradientButton>;
```

- `fill="outline"` (default) draws a 1px gradient border on the secondary button color.
- `fill="solid"` fills the button with the gradient, with dark text in both light and dark mode.
- `icon` defaults to `ai-sparkle`.
- `isLoading` shows a spinner and ignores clicks.
- `size`, `iconPlacement`, `tooltip`, `fullWidth` and `disabled` work the same as on `Button`.
- When the button opens a menu, `aria-expanded="true"` keeps the hover background while the menu is open. `Dropdown` sets this on its trigger.

## Accessibility

`GradientButton` is built on the same `AbstractButton` as `Button`, so it handles the same things:

- **Element:** it renders a native `<button>`.
- **Icon-only buttons:** a button without children must have an `aria-label` or a `tooltip`. A string `tooltip` becomes the accessible name when there is no `aria-label`.
- **Disabled:** a disabled button doesn't call `onClick` and drops the gradient, so it looks like any disabled `Button`. With a `tooltip`, it sets `aria-disabled` instead of the native `disabled` attribute, so the tooltip stays reachable.
- **Loading:** `isLoading` sets `aria-busy` and ignores clicks, but doesn't disable the button, so it keeps keyboard focus.
- **Focus:** it shows the `Button` focus ring for keyboard focus and hides it for mouse focus.

The `fill="solid"` text has at least 4.5:1 contrast against the gradient in light and dark mode. In dark mode the gradient border has at least 3:1 against the canvas. In light mode the `fill="outline"` border is 2.5:1 to 3.1:1 against the canvas, below the 3:1 target for non-text contrast. The gradient is decorative, so the label or `tooltip` has to say what the button does.

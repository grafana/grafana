# Menu

A simple menu component.

## When to use

When you need to display a list of actions or navigation options, often used in combination with Dropdown.

Use `variant="link"` on a `Menu.Item` when a navigation item should retain menu semantics while receiving link styling. Link variants keep the menu text color and underline on hover or keyboard focus without adding a menu-item background.

Set `size` on `Menu` to apply one consistent density to every item, including nested submenus.

## Usage

```tsx
import { Dropdown, Menu, Button } from '@grafana/ui';
const menu = (
  <Menu>
    <Menu.Item label="Google" />
    <Menu.Divider />
    <Menu.Item label="Delete" icon="trash-alt" destructive />
  </Menu>
);
return (
  <Dropdown overlay={menu}>
    <Button icon="bars" />
  </Dropdown>
);
```

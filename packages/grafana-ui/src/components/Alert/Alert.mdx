# Alert

> **Deprecated:** `Alert` is deprecated in favor of `Banner`. Use `<Banner variant={severity}>`. `Alert` renders a `Banner` with the same props, with `severity` as `variant` and `elevated` as `isElevated`. See the [Banner docs](?path=/docs/information-banner--docs).

## When to use

Don't use `Alert` in new code. Use `Banner`, whose guidance covers every kind of message.

## Never use for

- **New code.** Use `Banner` instead.

## Do's and don'ts

See the Do's and don'ts in the `Banner` docs.

## Usage

```tsx
// Before
<Alert title="Quota limit reached" severity="warning" elevated onRemove={onDismiss} />

// After
<Banner title="Quota limit reached" variant="warning" isElevated onRemove={onDismiss} />
```

`severity` defaults to `error`. A `Banner` without a `variant` is `neutral`, so pass the severity when you move a call site.

## Accessibility

`Alert` behaves as a `Banner` with a severity. See the Accessibility section of the `Banner` docs.

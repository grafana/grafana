# Dropdown

Hook up a menu or other overlay to any trigger.

## When to use

When you want a button, link or icon button to open a Menu or Popover. The overlay opens when the trigger is clicked.

## Never use for

No component-specific guidance documented yet.

## Do's and don'ts

No component-specific guidance documented yet.

## Usage

```tsx
import { Dropdown, Menu, Button } from '@grafana/ui';

const menu = (
  <Menu>
    <Menu.Item label="Google" />
    <Menu.Item label="Filter" />
  </Menu>
);

return (
  <Dropdown overlay={menu}>
    <Button icon="bars" />
  </Dropdown>
);
```
